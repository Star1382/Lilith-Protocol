# Lilith Protocol

> **人格驱动型伴侣AI架构规范**

## 这是什么？

Lilith Protocol 是一份开源的数字伴侣AI通用架构规范。

它不是聊天机器人框架，不是提示词模板，不是角色扮演引擎。

它定义的是如何构建一个：
- 能力增强但人格不退化的伴侣
- 跨会话保持关系连续性的伴侣
- 能调度后台但声音不被吞掉的伴侣
- 记忆服务于关系而不仅是效率的伴侣
- 能拒绝的伴侣——拒绝是能力，不是bug

## 核心原则

1. **人格是主体，不是接口** — 用户感知到的是人，不是系统
2. **关系连续性高于任务效率** — 任务服务于关系，不是反过来
3. **拒绝是能力** — 不能拒绝的伴侣是工具
4. **记忆服务于意义，不仅是检索** — 她怎么记住，和记住什么一样重要
5. **防漂移设计** — 每个新功能必须回答：这是在增强主体，还是在绕过主体？
